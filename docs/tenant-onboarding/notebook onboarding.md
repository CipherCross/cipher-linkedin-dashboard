# Установка агента Linked Helper на ноутбук

Эта инструкция — для человека без технического опыта. Вместо длинного списка
команд вы запускаете один файл. Сначала он только проверяет Linked Helper и
готовит отчёт. Данные отправятся на дашборд **только после того, как Микита
проверит цифры и вы отдельно запустите активацию**.

**Время:** обычно 10–20 минут на установку, затем несколько минут на активацию.

Агент читает локальную базу Linked Helper 2 (LH2) и после активации синхронизирует
её с `https://uitop.ciphercross.dev` каждые 30 минут. Он не изменяет файлы LH2.

## Что получить до начала

Для каждого ноутбука Микита присылает отдельную пару:

- номер ноутбука, например `uitop-1`;
- ключ доступа, который начинается с `lha.`;
- понятное название ноутбука можно придумать самостоятельно.

Не смешивайте номер от одного ноутбука с ключом от другого. Ключ показывается
только один раз и является паролем ноутбука: не отправляйте его в чат, отчёт или
скриншот.

Также получите архив установщика для своей системы. Распакуйте архив полностью
в обычную папку; не запускайте файл прямо внутри окна архива.

## 1. Проверить Python

Установщику нужен Python 3.10 или новее. Если Python уже установлен, переходите
к следующему разделу — скрипт сам проверит версию.

### Windows

Скачайте Python с <https://www.python.org/downloads/>. В первом окне установщика
обязательно включите **Add python.exe to PATH**, затем выберите **Install Now**.

### macOS

Скачайте и установите Python с <https://www.python.org/downloads/> со стандартными
настройками.

## 2. Установить и выполнить пробный запуск

Перед началом запустите Linked Helper, войдите в нужный аккаунт и дайте ему
поработать пару минут. Закрывать LH2 во время установки не нужно.

### Windows

Дважды нажмите `install-windows.cmd`.

Если Windows показывает защитное предупреждение, убедитесь, что архив получен
от Микиты. Не отключайте SmartScreen или антивирус для всей системы. Если
корпоративная политика не разрешает запуск, остановитесь и пришлите Миките текст
сообщения.

### macOS

Дважды нажмите `install-macos.command`.

Если macOS не открывает неподписанный файл, нажмите на него правой кнопкой,
выберите **Открыть**, затем ещё раз **Открыть**. Не отключайте Gatekeeper для
всего компьютера.

### Что спросит установщик

Введите по очереди:

1. номер ноутбука без изменений;
2. понятное название;
3. полный ключ `lha.` — при вводе ключ не отображается, это нормально.

Дальше установщик сам:

- создаёт защищённую папку `sync-agent` в домашней папке пользователя;
- скачивает закреплённую версию агента и проверяет её хеш, размер и версию;
- создаёт отдельное Python-окружение и устанавливает библиотеки;
- сохраняет ключ только в защищённом локальном `config.yaml`;
- находит базу LH2 и сохраняет диагностику;
- выполняет `sync --dry-run`, который ничего не отправляет;
- проверяет режим `only`, непустые данные и `parity ok`.

На этом установка останавливается. Автозапуск ещё не создаётся.

## 3. Отправить отчёт Миките

Установщик покажет путь к двум файлам в папке `sync-agent`:

- `onboarding-report.txt` — цифры пробного запуска и причины остановки, если они
  были;
- `inspect.txt` — структура найденной базы Linked Helper.

Пришлите Миките оба файла. Ключа доступа в них нет.

В нормальном отчёте сверху написано:

```text
Статус: ГОТОВО К СОГЛАСОВАНИЮ — НЕ АКТИВИРОВАНО
Parity: ok
```

Если написано `ОСТАНОВЛЕНО — НУЖНА ПОМОЩЬ С НАСТРОЙКАМИ`, ничего не удаляйте и
не исправляйте наугад. У разных версий LH2 отличаются таблицы; Микита проверит
`inspect.txt` и пришлёт исправленную настройку. После замены настройки снова
запустите тот же установщик и выберите повторную проверку.

Сравните вместе с Микитой таблицу кампаний из отчёта с цифрами в LH2: количество
людей, приглашений, принятых приглашений и ответов. Небольшая задержка между
интерфейсом LH2 и локальной базой возможна, расхождение в разы — нет.

## 4. Активировать после одобрения

Только когда Микита подтвердит цифры:

1. Снова запустите `install-windows.cmd` или `install-macos.command`.
2. Выберите **Активировать после одобрения Микиты**.
3. Скрипт повторит безопасный dry-run. Если данные изменились или появилась
   ошибка, он снова остановится без отправки.
4. Введите точную фразу, которую покажет скрипт, например
   `ОДОБРЕНО uitop-1`.

После подтверждения скрипт выполнит первую настоящую синхронизацию. Автозапуск
каждые 30 минут будет создан только если первая синхронизация закончилась
строкой `sync ok`. Затем скрипт сам проверит один запуск через системное
расписание.

На macOS используется личный LaunchAgent; на Windows — задание Task Scheduler
для текущего пользователя. Поэтому синхронизация работает, пока этот
пользователь вошёл в систему. Пропущенные запуски не теряют данные: следующий
запуск прочитает актуальную базу LH2.

## Проверить состояние позже

Повторно запустите установщик. После активации он покажет:

- номер ноутбука;
- состояние `active`;
- зарегистрирован ли автозапуск;
- последние строки `sync.log`.

Успешный журнал заканчивается строкой вида:

```text
sync ok: … rows delivered to the ingest gateway for instance uitop-1
```

## Если установщик остановился

Это безопасно: до отдельной активации он не отправляет данные и не включает
расписание.

| Сообщение или состояние | Что делать |
| --- | --- |
| Python 3.10 или новее не найден | Установить Python из раздела 1, закрыть окно и запустить скрипт снова |
| Ключ имеет неверный формат | Скопировать исходный ключ целиком; не пытаться дописывать его вручную |
| В папке уже есть агент без метки установщика | Ничего не удалять; прислать Миките сообщение и путь к папке |
| База Linked Helper `lh.db` не найдена | Запустить LH2 под нужным аккаунтом, подождать пару минут и выбрать повторную проверку |
| `Traceback`, нет колонки/таблицы или нужна помощь с настройками | Прислать `inspect.txt` и `onboarding-report.txt`; не запускать активацию |
| Нет `parity ok` или извлечение пустое | Прислать оба файла Миките; данные не отправлены |
| HTTP 401/403/503 во время активации | На ноутбуке ничего не менять; прислать Миките последние строки отчёта и `sync.log` |
| Скрипт не запускается из-за политики компании | Не отключать защиту; прислать точный текст сообщения Миките |

Не меняйте `instance_id`, не открывайте `config.yaml` на общем экране и не
удаляйте папку `sync-agent`, чтобы «начать сначала». Установщик специально
останавливается, если видит чужую или старую установку, чтобы не задвоить данные
и не потерять рабочую конфигурацию.

После активации агент обновляет себя через подписанный канал. Если проверка
обновления недоступна или подпись не проходит, текущая рабочая версия остаётся
на месте, а обычная синхронизация продолжается.
