## Implementation

- Added `users` with application-owned UUID identifiers and no provider
  subject/resource columns.
- Added `user_identities` with primary key `(user_id, provider)`, unique
  `(provider, provider_subject)`, canonical-user foreign key and cascade
  delete.
- Added required `team_members.user_id` with a unique canonical-user link and
  cascade delete; no provider identity column was added.
- Added `app_owner`, `app_runtime` and `app_readonly` as non-login,
  non-superuser, non-`BYPASSRLS` roles with no credentials in SQL. All public
  relations are owned by `app_owner`; runtime is not an owner.
- Revoked public schema/table/sequence access and granted runtime/read-only
  access explicitly. Runtime receives business DML and identity reads;
  identity/membership mutations remain server-owned identity API scope.
- Added transaction-local `app.actor_id` policy context. UUID parsing is
  guarded by a regex and `CASE`; missing, malformed, unknown, inactive or
  non-member actors fail closed.
- Enabled RLS on all 25 business tables plus `users` and `user_identities`.
  Active members share business rows; `users`, `user_identities` and
  `team_members` expose only the current actor boundary.
- Did not add stored functions, triggers, migration ledger or AI SQL guard;
  those remain S07 or later scope.

## Known limits

- The artifact is an empty-baseline companion. Existing memberships require a
  later controlled data-link/backfill procedure; S06 does not invent one.
- The SQL contract requires the server transaction wrapper to use `SET LOCAL
  app.actor_id`; S11 owns the driver/connection wrapper that makes this
  request lifecycle mechanical.
- `app_owner` is a non-login migration/owner role. RLS policies protect the
  non-owner runtime path; owner-level migration semantics remain intentionally
  separate from application authorization.
- Runtime business writes are shared-workspace writes for the 24 non-membership
  business tables. Fine-grained API authorization and identity lifecycle
  writes remain server-owned later work.
